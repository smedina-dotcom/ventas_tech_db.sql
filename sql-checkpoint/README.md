# RetailPro - Proyecto de Analítica de Datos y ETL

Este repositorio contiene la solución integral de inteligencia de datos para **RetailPro**, abarcando desde el diseño de la base de datos relacional en SQL Server hasta el modelado DAX y la maquetación del dashboard ejecutivo en Power BI.

## 🛠️ Herramientas Utilizadas
* **Base de Datos:** SQL Server (`Ventas_Tech_DB`)
* **ETL & Transformación:** Power Query (Lenguaje M)
* **Modelado & Métricas:** Power BI Desktop, DAX, Tabular Editor
* **Documentación & Versionado:** Git, GitHub, Google Docs

## 🚀 Estructura del Repositorio y Ejecución
1. `/sql/`: Scripts de creación de tablas e inserción de datos (`ventas_tech_db.sql`).
   * *Ejecución:* Abrir SQL Server Management Studio (SSMS), conectar a `localhost\SQLEXPRESS03` y ejecutar el script.
2. `/dashboard/`: Archivo `.pbix` con el modelo estelar y las medidas DAX (`Pipeline_ETL_Medina_Silvana.pbix`).
